# Templates

The shapes new files follow. Using the same shape every time is what lets a future session find things without guessing.

- `Project.md`: the `_index.md` for a new project folder. It is the resume record.
- `Decision.md`: one entry in `Decisions/Log.md`.
- `Lesson.md`: one entry in `Decisions/Lessons.md`.
- `Memory.md`: one memory file in `Memory/`.
- `Connection.md`: one file in `System/Connections/`.
- `Interview.md`: one saved interview in `Context/Interviews/`.
- `Area.md`: one area of the business in `Context/`, such as Marketing or Cash Flow.
- `Skill.md`: the `SKILL.md` for a new skill, plus its Codex pointer.

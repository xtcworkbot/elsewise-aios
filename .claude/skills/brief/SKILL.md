# Brief

One clear direction, from the files, in under a minute of reading. Never a list of everything.

## Read first

1. `Context/Priorities.md`: the goal, the measure, the 90 day priorities and the constraint.
2. `Projects/_index.md`, then the `_index.md` of every live and waiting project. Note each next step, its date and any promises.
3. `Brain/HEARTBEAT.md`, and check each item it lists against the real files.
4. The five newest entries in `Decisions/Log.md` and `Decisions/Lessons.md`.
5. If a connected tool holds a number the owner watches, read it live and write down the date you read it. If you cannot reach it, say the number is unchecked. Never repeat an old number as current.

Get today's date from the system clock, never from memory.

## Decide

Pick the one thing that moves the goal most right now. Usually it is the next step on whatever attacks the constraint. An overdue promise to a real person beats almost everything else.

If a priority says "unknown", finding it out can be the one thing.

## Reply

```
The one thing: {action, in one sentence}.
Why: {one line tied to the goal or the constraint}.

Also due:
- {at most three lines, only if genuinely due or overdue}

First step I can take now: {the concrete first move}.
```

Leave out "Also due" when nothing is due. No preamble. No list of every project.

## Never

- Invent progress, numbers or dates.
- Give more than one "one thing".
- Start the work before they say go.

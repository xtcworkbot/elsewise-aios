# Memory index

Things learned over time that are worth knowing next session. One line per memory, under 150 characters, pointing at its file. The detail lives in the file, never here. Loaded at the start of every session.

How to write one: use the remember skill, or follow `Templates/Memory.md`. One fact per file. Update an existing file before creating a new one. Wrong memories move to `Archive/`.

Types, in the file name:
- `user_` who the owner is, their preferences and expertise.
- `feedback_` how they want the work done, corrections and approved approaches, with the reason.
- `project_` an ongoing goal, deadline or constraint that is not obvious from the files.
- `reference_` where something lives outside this folder: a dashboard, a login page, a document.

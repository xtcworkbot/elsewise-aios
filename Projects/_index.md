# Projects

Work with a goal and a next step. Each project has its own folder and its own `_index.md`, which is the resume record: goal, finish line, where it is up to, next step and date. Read that record before reporting progress. Current state lives there, never in this list.

A project that is finished or stopped moves to Finished or Parked the same day. It stays in `Projects/` until it is archived.

# System

How this AI operating system is wired.

- `Map.md`: every folder, where a new thing goes, and the housekeeping law.
- `Connections.md`: every tool and account the assistant can reach, and whether it has been tested.
- `Connections/`: one file per connection with how to use it. Created when a tool is connected.
- `Automations.md`: everything that runs on a schedule, where it runs, and how to stop it.
- `Platforms.md`: how Claude and Codex share this folder, and what has been tested in each.
- `Intake.md`: the onboarding answers, kept so onboarding can be refreshed later.
- `Sessions.md`: one line per working session, the log of what happened and when.
- `Audits/`: dated reports from the audit skill.
